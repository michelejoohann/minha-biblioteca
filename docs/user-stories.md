# Histórias de usuário

## Acesso e família

- Como membro da família, quero entrar com segurança para acessar somente nossa biblioteca.
- Como administradora, quero gerenciar os membros e proprietários para representar corretamente a família.
- Como administradora, quero usar “Casa” como proprietário coletivo.

## Cadastro

- Como usuária, quero cadastrar um livro manualmente quando ele não tiver ISBN.
- Como usuária em uma livraria, quero informar ou escanear o ISBN para preencher os dados automaticamente.
- Como usuária, quero revisar os dados encontrados antes de salvar.
- Como usuária, quero indicar proprietário e localização de cada exemplar.
- Como usuária, quero ser alertada se a família já possuir o livro antes de concluir o cadastro.

## Busca e localização

- Como membro da família, quero buscar por título, autor ou ISBN para saber se temos um livro.
- Como leitora, quero filtrar por gênero, proprietário e status de leitura para escolher o que ler.
- Como membro da família, quero ver a localização exata para encontrar o exemplar rapidamente.

## Leitura

- Como leitora, quero registrar se quero ler, estou lendo, li ou abandonei uma obra.
- Como leitora, quero ver livros não lidos para descobrir opções na biblioteca de casa.

## Empréstimos

- Como proprietária, quero registrar para quem e quando emprestei um exemplar.
- Como proprietária, quero ver há quantos dias cada livro está fora.
- Como proprietária, quero registrar a devolução sem perder o histórico.

## Wishlist

- Como membro da família, quero guardar livros que desejamos comprar.
- Como compradora, quero receber um alerta se o desejo ou o catálogo já contiver o mesmo ISBN.
- Como compradora, quero transformar um item adquirido em exemplar do catálogo.

## Futuro

- Como usuária, quero fotografar uma capa ou lombada para iniciar um cadastro automaticamente.
